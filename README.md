Overview

Task Manager is a web application built with Python and Django that allows users to create, complete, undo, and delete tasks. My goal is to improve my software engineering skills by learning how to develop dynamic web applications and work with databases.

To run the application, execute:

- python manage.py migrate
- python manage.py runserver

Open http://127.0.0.1:8000/ in your browser.

Web Pages
- Home: Allows users to create new tasks.
- Task List: Displays tasks dynamically and allows users to complete, undo, or delete them.

Development Environment

- Language: Python, HTML, and CSS.
- Framework: Django.
